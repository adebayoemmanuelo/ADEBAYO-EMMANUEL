# Adebayo Emmanuel — Portfolio

Responsive personal portfolio. No build tools or package installation required.

## Preview
Open `index.html` in a browser.

## Profile image
The homepage image is stored at `assets/images/emmanuel.png`.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save. GitHub will display the published URL when deployment completes.

Content is adapted from the supplied CV. No performance figures or testimonials have been invented.
